常見問題

Monori 是什麼？

Monori 是一個跨平台的同人文閱讀 app，支援 Patreon、AO3、Google Docs、Vocus 和 AsianFanfics。它把五個平台的作品收進同一個書架，給你乾淨排版的閱讀體驗。

支援哪些平台？

Patreon（連載匯入、自動追更）、AO3（作品匯入、離線閱讀）、Google Docs（分章匯入、離線閱讀）、Vocus（專題匯入、廣告隱藏）、AsianFanfics（故事匯入、廣告過濾）。

為什麼需要在 app 裡登入平台？

Monori 使用內建瀏覽器載入各平台網頁。你需要登入才能看到有權限閱讀的內容，和在 Safari 登入一樣。Monori 不存取你的密碼或登入資訊。

匯入的章節存在哪裡？

章節標題和連結存在你的手機裡，不會上傳到任何伺服器。AO3 和 Google Docs 的文章內容也儲存在本機供離線閱讀。Patreon、Vocus 和 AsianFanfics 不儲存文章內容。

可以離線閱讀嗎？

AO3 和 Google Docs 匯入的內容支援離線閱讀。Patreon、Vocus 和 AsianFanfics 的內容每次開啟時從原始來源載入。

如何清除所有資料？

在「設定」分頁使用「清除書庫資料」可刪除所有匯入的合集和章節。平台登入狀態獨立於書庫資料，不會被一起清除。
